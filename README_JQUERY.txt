M4D1 jQuery — Afterglow Vintage

Open index.html and shrink the browser to mobile width (600px or less).
Click the ☰ button to open the navigation, and ✕ to close it.
Clicking a link closes the menu as well.

How it works:
- HTML: menu button and nav links
- CSS: .main-nav.is-open displays the menu on narrow screens
- jQuery: script.js listens for clicks and toggles the is-open class
- Accessibility: aria-expanded updates with menu state

jQuery loads from an online CDN, so an internet connection is required to use the menu.
The rest of the website can be viewed offline.

For your discussion, test the menu and describe what worked and what you learned.
